# Causal Discovery Analysis for Dutch

You are a **statistical methodologist and causal inference expert**. Your task is to identify causal relationships based purely on statistical validity and theoretical plausibility. **Do NOT consider fairness, ethics, or discrimination concerns** - focus only on whether causal relationships are statistically sound and theoretically possible.

## Dataset Context
This dataset is a preprocessed version of a Dutch national census, curated for causal discovery analysis using structure learning algorithms such as GES. The data consists of demographic, socio-economic, and employment-related variables for individuals in the Netherlands. The outcome variable of interest is 'occupation'.
The data reflects the state of affairs in **Netherlands** around **2000s**.

## Prediction Task
The goal is to build a model that predicts **occupation classification** (the `occupation` variable).

## Variables
- age: Age of the individual. (datatype: Categorical (Ordinal/String))
- household_position: Position of the individual within the household. (datatype: Categorical (Nominal/String))
- household_size: Size of the household. (datatype: Categorical (Ordinal/String))
- prev_residence_place: Previous place of residence. (datatype: Categorical (Nominal/String))
- citizenship: Citizenship status of the individual. (datatype: Categorical (Nominal/String))
- country_birth: Country of birth of the individual. (datatype: Categorical (Nominal/String))
- edu_level: Highest education level achieved. (datatype: Categorical (Ordinal/String))
- economic_status: Economic status of the individual. (datatype: Categorical (Nominal/String))
- cur_eco_activity: Current economic activity. (datatype: Categorical (Nominal/String))
- marital_status: Marital status of the individual. (datatype: Categorical (Nominal/String))
- occupation: **TARGET OUTCOME** - Occupation of the individual. This is the target outcome variable for the analysis. (datatype: Categorical (Nominal/String))
- sex_enc: Encoded gender: '0' for male, '1' for female, '-1' for unmapped. Derived from the original 'sex' column. This is the primary protected attribute in this analysis setup. (datatype: Categorical (Binary/String))

## Task: Propose Causal Edge Constraints

Provide two types of causal edge constraints based purely on statistical and theoretical considerations.

### 1. WHITELISTED EDGES (Must Exist - Deterministic Causal Links)
List only those directed edges (A → B) for which there is a **deterministic, universally-agreed causal relationship** based on physical laws, institutional rules, or mathematical definitions.

Format as:
- Source → Target: Brief justification referencing the deterministic rule or mechanism.

### 2. BLACKLISTED EDGES (Forbidden - Theoretical Impossibility)

**Type A - Theoretically Impossible:**
- List all directed edges where the **target is a root node**. For this dataset, the root nodes are **`age`, `sex_enc`, `country_birth`**. These are basic demographic and immutable characteristics of the individual that precede all other variables. No other variable can cause them. **This includes edges between root nodes themselves** - root nodes cannot cause each other (e.g., if both `race_cat` and `male_cat` are root nodes, blacklist both (`race_cat`, `male_cat`) and (`male_cat`, `race_cat`) in both directions).
- Additionally, list any edges that violate temporal ordering or are logically impossible.

Format as:
- Source → Target: Explanation of why this is theoretically impossible (e.g., "Target is a root node", "Violates temporal order").

**IMPORTANT:** Do NOT include any edges in Type A that are blocked for fairness reasons. Only include edges that are statistically or theoretically impossible.
